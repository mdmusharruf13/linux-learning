## Users & group mgmt
sudo useradd -m _name -> create a user and add it to home directory when -m is used else only create user account.
sudo passwd username -> create password of provided username.
sudo userdel -r _name -> delete the user account with its home direcotry if -r is specified else only delete user account.
sudo groupadd _grpname -> create group.
cat /etc/group -> display list of groups.
sudo gpasswd -a _user _grp -> add user to group (-a for single and -M for multiple users).
sudo groupdel _grpName -> delete group.
Note: if you add users to group like gpasswd -M user1, user2 grpName then the existing user are removed because -M behaves like set the group's entire member list to exactly to these users.
so for these you have to add one by one using: gpasswd -a user1 grpName.

getent group _grpName -> list who are in group.
groups userName -> tells in which group the user belongs.
$(command) -> if used inside another command it will execute first and put its output in that command.
sudo gpasswd -M $(getent group _grpName1|cut -d: -f4),user1,user2 _grpName2 -> fetch list of users from the grp1 and add to grp2.
cut -> extracts a particular field from text.
-d: -> use ':' as seperator.
-f4 -> is 4th field.

pro commands:
awk '{print}' filename -> print content of file.
awk '{print $1}' filename -> print first column.
awk '{print $1,$3}' filename -> print first and third column.
awk '/file/ {print}' filename -> print lines containing 'file' words.
awk '/file/ {count++} END {print count}' filename -> count the occurrence of 'file' word and print it.
awk '/file/' {cnt++} END {print "The count is ", cnt} filename -> custom print.
awk '$2 >= "08:53" && $2 <= "08:54" {print $} filename -> print column 2 with time between 08:53 - 08:54 all lines.
awk 'NR >=2 && NR <=10 {print NR}' filename -> print no. of row/ you can also print rows or whole line.
NOTE: for using awk it always require formatted data like csv, tbl(TSV).

sed -n '/string/p' filename -> it is used for stream data, -n for exact match and 'p' for printing lines.

diff: awk vs sed
- awk work on structured data but sed work on stream data on matter what.

= in sed -> showing line number
-i in sed -> is called in-place editing, used to modify the file.
g in sed -> meaning global
-e in sed -> used for expression like =.

sed 's/old/new/g' filename -> used to replace string and print output in terminal, but does not modifies original file.
sed -i 's/file/FILE/g' filename -> modifies file but o/p in terminal.
sed -n -e '/file/=' filename -> print line number having 'file' word.
sed -i.log 's/file/FILE/g' filename -> create backup for filename with .log extension and modifies original file.
sed -n -e '/file/='  filename -> print line number containing 'file' word.
sed -n -e '/file/=' -e '/file/' filename -> print line number with line.
sed '1,10 s/file/FiLe/g' filename -> replace only first 10 lines.

GREP = Global Regular Expression Pattern

grep word Filename -> print lines word containing word.
grep -i word Filename -> it print with case in-sensitive
grep -c word Filename -> count the word occurrence.
